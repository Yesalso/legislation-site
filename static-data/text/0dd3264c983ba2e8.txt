第33/2023/COA號決議草案
政務委員會，
回顧政務委員會歷次會議及其所做出的決定或決議，
回顧到決議草案29/2023/COA的內容，
回顧第六十週，第五十九周，第五十八周在校學習情況，
表示肯定在第六十週，第五十九周，第五十八周在校內的探索新制度的嘗試，
認為在過去三周裡，在校期間存在嚴重的時間浪費的現象，
認為有改變過去浪費時間現象的必要，
決心採取必要措施，
1. 決定規範每週在校學習時間，
2. 決定將每週自習時間作出如下分配：
|  | 周日 | 週一 | 週二 | 週三 | 週四 | 週五 |
| --- | --- | --- | --- | --- | --- | --- |
| 晚修（一）19：30起 | 自行決定 | 數學 | 數學 | 數學 | 語文 | 地理 |
| 晚修（二） |  | 化學 | 物理 | 物理 | 化學 | 英語 |
| 語文課 |  |  | 物理 | 語文 | 物理 | 數學 |
| 自習課 |  |  |  | 英語 |  | 物理 |
3. 決定每日監督第2段之完成情況，
4. 決定每節課課前得預習該節課之可能學習之知識，
5. 決定在午休期間對完成題目情形進行通報，
6. 決定在晚修（一）前30分鐘（即19：00-19：30）對該日所學進行總結，
7. 決定如遇緊急特別情況或無條件執行第2段之時間安排，可由主任委員決定是否繼續執行第2段中所規定的內容或修改調換該時段之任務，
8. 決定繼續積極處理此案。
